# African Languages Dataset

This dataset contains a comprehensive list of African languages, extracted from the [Glottolog](https://glottolog.org/) database.

## Contents

- `african_languages.csv`: The filtered dataset containing only languages from the "Africa" macroarea.
- `extract.py`: The Python script that was used to filter the original dataset.

## Original Data Source

The original dataset `languages_and_dialects_geo.csv` was downloaded from Glottolog (Version 5.3).
Glottolog data is licensed under a Creative Commons Attribution 4.0 International License.

## Usage

This dataset can be pushed to GitHub to host your own African Languages dataset.
